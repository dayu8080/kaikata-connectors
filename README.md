# Коннекторы Kaikata

Каталог дополнений для [Kaikata](https://github.com/dayu8080/kaikata-releases). Коннектор — это не отдельное приложение: его ставят прямо в Kaikata (Настройки → Коннекторы), и он появляется там отдельной вкладкой.

- `main` — каталог для всех пользователей.
- `beta` — тестовые версии, их видят только телефоны с включённым бета-тестированием.

Файлы `.kaikata` подписаны ключом Kaikata: изменённый или чужой файл приложение не установит.
